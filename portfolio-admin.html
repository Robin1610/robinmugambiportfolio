📄 CV / Resume Download File
▼
How CV hosting works: Your CV must be publicly accessible via a URL.
Upload your PDF to Google Drive (set to "Anyone with the link can view"), Dropbox, or any public host — then paste the direct download link below.

Google Drive tip: After sharing, replace /view with /export?format=pdf in the URL for a direct download.
Paste the direct link. Site visitors will open this URL when they click "Download CV".

✉ Contact Form (EmailJS) Message Delivery
▼
Setup (free, 200 emails/month):
1. Create a free account at emailjs.com
2. Add an Email Service (Gmail works great) → note the Service ID
3. Create an Email Template with variables: {{from_name}}, {{reply_to}}, {{subject}}, {{message}} → note the Template ID
4. Go to Account → API Keys → copy your Public Key
5. Paste all three below and export the JSON. The contact form will send emails directly to you.

If left blank: the form falls back to opening the user's mail client with a pre-filled mailto.
